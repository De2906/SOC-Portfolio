# Printer & Peripheral Troubleshooting

## Overview
This lab documents troubleshooting a printer issue on a Windows system. The goal was to identify the cause of the problem and restore normal printing functionality for the user.

## Issue Description
A user reported that their printer was not printing documents and was showing an error status.

## Environment
- Operating System: Windows 11  
- Device: Network printer  
- Connection Type: Network / USB  
- User Type: Standard user  

## Troubleshooting Process
1. Verified the issue by sending a test print job.
2. Checked printer status and confirmed it was set as the default printer.
3. Restarted the printer and cleared the print queue.
4. Verified the printer was online and reachable on the network.
5. Restarted the Print Spooler service.
6. Removed and re-added the printer to the system.
7. Installed updated printer drivers from the manufacturer website.

## Resolution
After reinstalling the printer and updating the drivers, the printer resumed normal operation. The user confirmed that documents printed successfully.
