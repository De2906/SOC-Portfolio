# SOC Portfolio

This repository showcases hands-on IT Support and Security Operations (SOC) projects.

## IT Labs
The IT-Labs folder contains practical, real-world troubleshooting labs that reflect common help desk and IT support tasks, including:
- User account and access troubleshooting
- Network connectivity issues
- Software installation and repair
- Printer and peripheral troubleshooting

These labs demonstrate my ability to support end users, diagnose technical issues, and clearly document solutions.

## SOC Incident Reports
The Incident Reports folder contains security-focused documentation showing how I analyze alerts, review logs, and document security events. These reports reflect entry-level SOC analyst responsibilities such as:
- Authentication and login alerts
- Endpoint and malware activity
- PowerShell and suspicious behavior analysis
- Incident documentation and escalation decisions

## Skills Demonstrated
- IT Support & Help Desk Troubleshooting
- User Access & Permissions
- Networking Fundamentals
- Security Alert Analysis
- Incident Documentation
- Clear Technical Communication

This portfolio is designed to show both technical ability and problem-solving skills across IT support and cybersecurity roles.
