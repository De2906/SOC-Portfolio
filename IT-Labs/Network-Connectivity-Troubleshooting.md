# Network Connectivity Troubleshooting Lab

## Issue Summary
User reported loss of internet connectivity on a Windows workstation. The device was unable to connect to the wireless network.

## Environment
- OS: Windows 10/11
- Network Type: Wireless (Wi-Fi)
- User Role: Standard end user

## Troubleshooting Steps
1. Verified the reported issue by checking network status.
2. Confirmed Wi-Fi was not connected to any network.
3. Checked adapter settings and found the wireless adapter was disabled.
4. Re-enabled the Wi-Fi adapter.
5. Reconnected to the correct wireless network.

## Resolution
Wireless adapter was disabled. After re-enabling the adapter and reconnecting to the correct Wi-Fi network, internet access was restored.

## Verification
- Device successfully connected to Wi-Fi
- Internet access confirmed by loading external websites

## Lessons Learned
Basic network connectivity issues can often be resolved by checking adapter status and connection settings before escalating.
