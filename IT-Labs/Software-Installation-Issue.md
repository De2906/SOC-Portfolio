# Software Installation & Repair Troubleshooting

## Overview
This lab documents troubleshooting a failed software installation on a Windows system. The goal was to identify why the application was not working correctly and restore it to a usable state for the user.

## Issue Description
A user reported that an application failed to install properly and would not launch after installation.

## Environment
- Operating System: Windows 11  
- Application: Google Chrome  
- User Type: Standard user  

## Troubleshooting Process
1. Attempted to launch the application to confirm the issue.
2. Checked Task Manager to verify the application was not running in the background.
3. Uninstalled the application using Programs and Features.
4. Restarted the system to clear any locked files or services.
5. Downloaded a fresh installer from the official vendor website.
6. Reinstalled the application using administrator privileges.

## Resolution
After reinstalling the application using a clean installer and elevated permissions, the software launched successfully. The user confirmed normal functionality.
